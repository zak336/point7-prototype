# Point7 Hackathon Prototype
## Run
1. Install Python 3.10+.
2. In this folder run `pip install -r requirements.txt`
3. Run `streamlit run app.py`
4. Open the local URL printed by Streamlit (usually http://localhost:8501).

## Demo
Choose “Sort customer enquiries and draft replies”, click **Generate workflow**, show the orchestration steps and model recommendation, expand the JSON, then click **Run simulated test** and **Export workflow JSON**.

## Honest limitations
This prototype demonstrates a planned workflow and transparent rule-based routing. It does not call a live model API, connect to external services, or deploy an actual agent. Present it as an early proof of concept.
